# 榧の種 · A seed of kaya

*Rob Oudendijk · 御杖プロジェクト · Mitsue Project · 2026*

---

| 日本語 | English |
|--------|---------|
| この種は急がない。<br>十八ヶ月かけて熟し、<br>百年かけて<br>碁盤になる木へ育つ。 | *This seed does not hurry.*<br>*Eighteen months to ripen.*<br>*A century to become the board*<br>*on which the next generation plays.* |
| 今日、わたしたちは<br>同じ問いを持ち寄った——<br>過疎の村に残るものは何か、<br>森は誰のためにあるのか、<br>電力は誰が決めるのか。 | *Today we arrive with*<br>*a shared question:*<br>*What remains in a village that empties?*<br>*Whose forest is this?*<br>*Whose hand turns on the lights?* |
| この種が問うのは、<br>わたしたちが答えを持っているか<br>ではなく、<br>二十五年後も<br>ここにいるかどうかだ。 | *This seed does not ask*<br>*whether we have answers.*<br>*It asks only whether*<br>*we will still be here*<br>*in twenty-five years, tending*<br>*what we planted.* |
| 榧は神社の木だ。<br>時間の証人として立つ。<br>この小さな種を、<br>その精神の端くれとして<br>受け取ってほしい。 | *Kaya is a shrine tree.*<br>*It stands as witness to time.*<br>*Please receive this small seed*<br>*as a fragment of that spirit —*<br>*and of ours.* |
| 御杖村のために。<br>そして、まだ生まれていない<br>人たちのために。 | *For Mitsue village.*<br>*And for those*<br>*not yet born.* |
