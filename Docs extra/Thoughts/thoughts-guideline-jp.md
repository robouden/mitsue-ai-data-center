# プロジェクト指針 — 理念と実務の整合

この文書は、[thoughts-clean.md](thoughts-clean.md) に記した思いを、指針（原則）と具体的な
「やるべきこと」の一覧に落とし込んだものです。契約書ではなく、羅針盤です。判断に迷ったときは
ここに立ち返り、こう問いかけてください。*この選択は、森と、村の年長者と、その孫たちを敬うものか？*

---

## 指針となる原則

1. **森こそが力の源である。** すべては年長者が植えた木々から始まる。エネルギーも、計算資源も、
   記憶も、そして手仕事も、すべて地元の森に源を持つ。

2. **年長者の知恵こそが本当の中身である。** AIデータセンターは、単に計算資源を売るためではなく、
   村の記憶と知恵を受け継ぎ、未来へ運ぶために存在する。

3. **学びを、始まりの場所へ戻す。** 学び（そしてデータセンター）を学校の中に置き、孫たちが
   祖父母と同じ場所で学べるようにする。

4. **世代を越える先見の明を敬う。** 若い世代は、年長者が植えたものを見て、その先見の明を
   大切にすべきである。たとえそれが、年長者が当初思い描いた形とは違っていたとしても。

5. **地元の手で、地元の木で、地元の資金で。** 手仕事（机、ビリヤードのキュー、テーブル）は、
   丹羽さんのような地元の作り手が、近くの森の木で作る。資金は地元の金融でまかない、外部の
   不透明な建設資金には頼らない。

6. **「接着剤」とは、実体のある事業構造である。** 思いや物語だけでは足りない。この理念は、
   その下に健全で強靭な事業・組織の構造があってこそ生き続ける。

7. **一度の催しではなく、数十年のために築く。** 華やかさよりも強靭さを。

## やるべきこと

### A. 物語を定める（土台）

- [ ] [thoughts-clean.md](thoughts-clean.md) を、本プロジェクトの正式な理念文書として採用する。
- [ ] パートナーと村人向けに、理念を1ページの日英二言語でまとめる。
- [ ] 年長者の物語と知恵を記録する（音声・映像）。それがデータセンターが最初に守る「記憶」となる。

### B. 森 → 力 の連鎖

- [ ] 近くの森からの持続可能な木材・間伐材の供給を確認する（バイオマス計画と紐づける）。
- [ ] 森 → エネルギー → 計算 が物理的にどうつながるかを図にする（用地、ボイラー／CHP、
  
      データセンターの場所）。
- [ ] この循環が次世代へ続くよう、再造林の約束を定める。

### C. 学校／データセンター

- [ ] 地元のAIデータセンターを学校内（または隣接地）に置く合意を得る。
- [ ] データセンターを生きた教材として活用する教育プログラムを設計する。
- [ ] 学校に隣接する施設としての電力・冷却・安全要件を確認する。

### D. 地元の手仕事

- [ ] 地元の手仕事、地元のヒノキで、丹羽さん／地元の作り手に発注する。

### E. チームと「接着剤」

- [ ] 技術・金融・人材の専門家からなる組織づくりを続ける。
- [ ] 数十年に耐える構造を設計するため、教育と経済の助言者を迎える。
- [ ] 事業・法的な構造を定める（誰が所有し、誰が運営し、収益がどう地元へ還元されるか）。

### F. 資金

- [ ] 地元の資金源を優先し、外部の建設利権への依存を避ける。
- [ ] 資金計画を本プロジェクトのEVM／予算ベースラインと紐づける。

## この文書の使い方

- 新しい判断・パートナー・支出が明らかに理念に合わないと感じたら、必ず立ち返る。
- 完了した項目はチェックリストを更新する。原則そのものは安定させておく。
- 原則と実務上の制約が本当に衝突する場合は、その衝突を率直に言葉にし、意図的に判断する。
  黙って原則を捨ててはならない。
