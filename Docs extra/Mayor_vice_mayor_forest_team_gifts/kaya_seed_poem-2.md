# 榧の種 · A seed of kaya

_Rob Oudendijk · 御杖プロジェクト · Mitsue Project · 2026_

---

| 日本語                                                       | English                                                      |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| この種は急がない。<br>十八ヶ月かけて熟し、<br>百年かけて<br>碁盤になる木へ育つ。 | _This seed does not hurry._<br>_Eighteen months to ripen._<br>_A century to become the board_<br>_on which the next generation plays._ |
| 今日、わたしたちは<br>同じ問いを持ち寄った——<br>過疎の村に残るものは何か、<br>森は誰のためにあるのか、<br>電力は誰が決めるのか。 | _Today we arrive with_<br>_a shared question:_<br>_What remains in a village that empties?_<br>_Whose forest is this?_<br>_Whose hand turns on the lights?_ |
| この種が問うのは、<br>わたしたちが答えを持っているか<br>ではなく、<br>二十五年後も<br>ここにいるかどうかだ。 | _This seed does not ask_<br>_whether we have answers._<br>_It asks only whether_<br>_we will still be here_<br>_in twenty-five years, tending_<br>_what we planted._ |
| 榧は神社の木だ。<br>時間の証人として立つ。<br>この小さな種を、<br>その精神の端くれとして<br>受け取ってほしい。 | _Kaya is a shrine tree._<br>_It stands as witness to time._<br>_Please receive this small seed_<br>_as a fragment of that spirit —_<br>_and of ours._ |
| 御杖村のために。<br>そして、まだ生まれていない<br>人たちのために。 | _For Mitsue village._<br>_And for those_<br>_not yet born._  |
| この⼩さな種を、 <br>その魂のかけらとして ,<br>受け取ってほしい | *These tiny seeds, <br>I hope you will accept this as a fragment of that soul.* |
