1. **日時：** 令和【　】年【　】月【　】日　【　】時【　】分〜
2. **場所：** 【開催場所】
3. **設立時社員総数：** 【2】名　**出席者数：** 【2】名

**議長選出：** 出席社員の互選により、【氏名】を議長に選出した。議長は本総会の成立を宣言した。

**第1号議案　定款承認の件**
議長は、別紙定款案を朗読し、その承認を求めたところ、出席社員全員一致をもって異議なく承認可決した。

**第2号議案　設立時理事選任の件**
議長は、設立時理事の選任を求めたところ、出席社員全員一致をもって次のとおり選任し、被選任者はいずれも就任を承諾した。（本法人は理事会及び監事を置かない。）

- 設立時理事：【氏名①】、【氏名②】、【氏名③ — 他の理事と親族関係のない者】

**第3号議案　設立時代表理事選定の件**
設立時理事の互選により、設立時代表理事に【氏名】を選定し、同人は就任を承諾した。

**第4号議案　主たる事務所の所在場所決定の件**
主たる事務所を奈良県宇陀郡御杖村【番地】に置くことを全員一致で決議した。

議長は以上をもって全ての議案の審議を終了した旨を述べ、閉会を宣言した。上記の決議を明確にするため、議長及び出席社員はこの議事録に記名押印する。

# 書類4 — 法務局提出書類チェックリスト

**奈良地方法務局へ、設立総会の日から2週間以内に提出。登録免許税 ¥60,000（収入印紙）。**

- [ ] 設立登記申請書（一般社団法人設立登記申請書）
- [ ] 登録免許税 ¥60,000 分の収入印紙（貼付台紙）
- [ ] 定款（公証人の認証を受けたもの）— [mitsue_teikan_draft_jp.md](mitsue_teikan_draft_jp.md)
- [ ] 設立総会議事録 — 書類1
- [ ] 設立時代表理事を選定したことを証する書面（設立時理事の互選書）
- [ ] 設立時理事・代表理事の就任承諾書 — 書類2（監事なし）
- [ ] 代表理事の印鑑証明書（発行後3か月以内）
- [ ] 印鑑届出書（法人代表者印）— 法人実印を事前に作成（¥5,000–¥15,000）
- [ ] 設立時社員名簿 — 書類3
- [ ] （必要に応じ）本人確認証明書・委任状

**登記完了後：**
- [ ] 登記事項証明書を取得（¥600/通）— 銀行・税務署・助成金用に複数部
- [ ] 法人口座開設（南都銀行／ゆうちょ 等）
- [ ] 税務署・県税事務所・村役場へ法人設立届出（登記後2か月以内、無料）
- [ ] 法人番号（13桁）を国税庁サイトで確認（自動付与）

> **紙の上で完結しない作業：** ①法人実印の作成、②各設立者の個人実印の印鑑証明書を市区町村役場で取得、③公証人役場（奈良／桜井）の定款認証予約（電子公証が速い）。
