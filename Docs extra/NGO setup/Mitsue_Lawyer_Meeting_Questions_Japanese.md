# 法律相談質問リスト（日本語版）

---

### 🏢 会社構造と法的形態

1. **一般社団法人 vs NPO法人：**
   - 一般社団法人の実際には有利な点は何ですか？
   - 5年後にNPO法人に移行するタイミングはいつが最適ですか？
   - 一般社団法人として設立してからNPO法人に移行する手順はありますか？

2. **会社構造設計：**
   - 取締役会構成（1人 vs 3人）の法的リスクとメリットは何ですか？
   - 各取締役の責任範囲の境界線を引くための推奨構成は何ですか？
   - 公平な利益相反ポリシーを策定する方法は何ですか？

3. **社員と取締役の重複について：**
   - 社員を取締役にすることができますか？それは wise ですか？
   - 理事と社員を同時にすることは、将来のNPO法人移行に支障をきたしますか？

5. **許認可とライセンス：**
