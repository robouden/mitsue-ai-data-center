# 適法性・登記書類 セルフチェックリスト
**目的：弁護士なしで、定款の適法性と登記書類の正確性を、日本の無料公的窓口を使って確認する。**

関連草案：[定款](mitsue_teikan_draft_jp.md)・[設立書類セット](mitsue_founding_assembly_docs_jp.md)

---

## A. 定款の適法性セルフチェック（認証前）

**A1 — 絶対的記載事項（一つでも欠けると無効）：**
- [ ] 名称（「一般社団法人」を含む）— 第1条
- [ ] 目的 — 第4条
- [ ] 主たる事務所の所在地 — 第2条
- [ ] 設立時社員の氏名・住所 — 第31条
- [ ] 社員の資格の得喪に関する規定 — 第6〜10条
- [ ] 公告方法 — 第3条
- [ ] 事業年度 — 第23条

**A2 — 非営利型（法人税非課税）の定款要件：**
- [ ] 剰余金を分配しない旨を明記 — 第26条
- [ ] 解散時の残余財産を国・地方公共団体・公益法人等に帰属させる旨 — 第29条
- [ ] 残余財産を社員に分配しない旨を明記 — 第29条
- [ ] 特定の個人・団体に特別の利益を与える定めがない

**A3 — 役員・親族要件（非営利型・理事会非設置・監事なし）：**
- [ ] 理事3名以上を選任 — 第17条
- [ ] 設立時社員2名以上を確保（1名では設立不可。Yuka 不参加の場合は代替の第2社員を確保）
- [ ] ⚠️ 各理事について「本人＋親族等」が理事総数の **3分の1以下** — 3名なら親族関係の2名を含めない
- [ ] 代表理事を理事の互選で選定 — 第18条
- [ ] 理事会・監事は置かない（定款 第17条と整合）

**A4 — 名称・所在地の事前確認：**
- [ ] 同一住所・同一名称の法人がないか「登記情報提供サービス」で確認
- [ ] 事務所所在地が確定（旧菅野小を使う場合は **村の使用承諾書** を取得）

---

## B. 無料の公的チェック窓口（3つすべて利用）

**B1 — 公証人 事前確認（適法性の保証）：**
- [ ] 完成した定款案を最寄りの公証人役場（奈良／桜井）へメールで送付し事前確認を依頼
- [ ] 公証人の指摘箇所をすべて修正（公証人は不適法な定款を認証しない＝法令適合の保証）
- [ ] **電子定款認証** を選択（手続きが速い。※一般社団法人の定款には ¥40,000 の収入印紙は元々不要 — 株式会社のみの課税）
- [ ] 認証予約を取り、認証手数料 ¥52,000（手数料約¥50,000＋謄本代）を準備（実印・本人確認書類持参）
- [ ] ※認証手数料は法定費用で、自分で全書類を作成しても省略不可（公証人による認証は必須）

**B2 — 法務局 登記手続案内（提出前の無料確認）：**
- [ ] 奈良地方法務局の「登記手続案内」（無料・要予約 約20分）を予約
- [ ] 設立登記申請書・添付書類一式を持参し、記載内容を事前チェックしてもらう
- [ ] 指摘事項を修正

**B3 — 無料作成サービスとの照合：**
- [ ] freee会社設立 または マネーフォワード クラウド会社設立 で「一般社団法人」を選択し入力
- [ ] 自動生成された定款・設立登記申請書を本草案と照合（内容一致を確認）

**B4 —（任意・低コスト）非営利型の税務確認：**
- [ ] 税務署の法人設立窓口 or 税理士スポット相談で、非営利型の要件充足を確認

---

## C. 登記書類の正確性（設立登記申請書）

**C1 — 申請書 本体：**
- [ ] 様式は法務局公式ひな形（記載例）を使用
- [ ] 名称・主たる事務所・目的が定款と完全一致
- [ ] 設立時理事・代表理事の氏名／住所が議事録・就任承諾書と一致
- [ ] 公告方法の記載が定款と一致
- [ ] 登記すべき事項を別紙（またはオンライン）で正確に記載

**C2 — 添付書類：**
- [ ] 認証済み定款
- [ ] 設立総会議事録（または設立時社員の決定書）
- [ ] 設立時代表理事の選定を証する書面（設立時理事の互選書）
- [ ] 就任承諾書（設立時理事全員・代表理事。監事なし）
- [ ] 代表理事の印鑑証明書（発行後3か月以内）
- [ ] 印鑑届出書（法人代表者印）
- [ ] 設立時社員名簿

**C3 — 費用・期限：**
- [ ] 登録免許税 **¥60,000**（収入印紙）
- [ ] **設立総会の日から2週間以内** に奈良地方法務局へ提出
- [ ] 法人実印を事前作成（外枠＝法人名／内枠＝代表理事之印、1辺1cm超3cm以内、丸18mm目安）
- [ ] 各設立者の個人実印・印鑑証明書を準備

---

## D. 登記完了後の届出

- [ ] 登記事項証明書を複数取得（¥600/通：銀行・税務署・助成金用）
- [ ] 法人口座開設（南都銀行／ゆうちょ）
- [ ] 法人設立届出書 → 税務署（登記後2か月以内）
- [ ] 法人設立届出書 → 奈良県税事務所・御杖村役場
- [ ] 法人番号（13桁）を国税庁サイトで確認
- [ ] （非営利型）青色申告承認申請書・給与支払事務所等の開設届出（必要に応じ）

---

> **要点：** A欄をすべて満たした上で、**B1（公証人）＋B2（法務局案内）** の2つの無料確認が、定款と書類の適法性を実質的に保証する＝弁護士不要の安全網。
