# 御杖村森林組合　御中

> 先人が植えた森が、今、村に豊かさをもたらす。

---

先日はおいしいお野菜をありがとうございました。いつも温かく迎えてくださり、大変嬉しく思っています。

以前お渡しした「**つえみ姫と七人の森の精**」を覚えていらっしゃいますか。物語の中に、森を守る精霊「**もりき**」が登場します——どんぐりや在来種の木を植えながら、この谷の未来をつくっていく存在です。

その「もりき」の役を担えるのは、御杖村森林組合さんではないかと思っています。

改めてお時間をいただけますでしょうか。森の手入れ、木材チップの活用、そして在来種の植え直しについて、まずは**夢の話**をご一緒できたら嬉しいです。むずかしい話ではなく、まずは可能性を一緒に考えてみたいと思っています。

ご都合のよい日をいくつかお教えいただければ幸いです。どうぞよろしくお願いいたします。
