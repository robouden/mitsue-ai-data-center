- **宛先の考え方:** 情報公開条例上の「実施機関」は通常**村長**です。そのため正式な請求書は **御杖村長宛**とし、受付・処理を行う窓口として **総務課**に提出します（下の送付状は総務課宛）。Rob asked to send this *to the 総務課* — that's correct as the handling window; the formal request is legally addressed to the mayor.
- **提出先 / Send to:**
  御杖村役場 総務課
  〒633-1302 奈良県宇陀郡御杖村大字菅野368番地
  TEL 0745-95-2001 ／ FAX 0745-95-6800
- **方法 / Method:** 窓口持参・郵送・FAX のいずれか。可能なら事前に総務課へ一報し、(a) 御杖村情報公開条例の正式名称・根拠条文、(b) 所定の請求書様式の有無、(c) 写し交付手数料（通常 1枚10円程度）と郵送料、を確認するとスムーズです。
- **氏名・住所・連絡先**の空欄（`____`）を記入してから提出してください。
- **費用:** 写しの作成手数料・郵送料は請求者負担が通常です。電子データ(PDF)交付が可能か併せて依頼しています。
- **回答期限:** 多くの自治体で受付から **14日以内**に開示決定（延長あり）。

村が令和4年度（2023年〔令和5年〕2月完成）に整備した、村西側入口・国道沿いの「トイレ休憩所」（伊勢本街道沿い、総事業費約9,500万円）の整備事業に関する次の文書。設計・用地取得等が令和3年度以前に行われている場合は、当該年度の関連文書を含む。

2. 入札公告、指名通知書、見積依頼書その他入札・契約手続に関する文書

5. 工事費内訳書・設計書（**積算内訳・数量内訳**が分かるもの）
