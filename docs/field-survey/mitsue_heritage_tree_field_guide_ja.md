# 御杖村 母樹・郷土樹 野外調査ガイド

**目的** — 本ガイドは御杖村の在来「母樹」（野生動物の餌となり、次世代の森を育てる老齢広葉樹）を見つけ・同定し・記録するための野外ツールです。**1ページ目で同定 → 2ページ目で記録。**

**測定方法** — 胸高直径(DBH)は地上1.3mで測定。母樹＝種子源として保全すべき健全な老齢結実木。
