# Heritage Tree Field Guide

**Purpose** — Locate, identify and record Mitsue's native "mother trees" — old, seed-bearing broadleaf trees that feed wildlife and seed the next forest.

## Native species checklist

| ✔ | Species | Latin name | Habitat in Mitsue | Wildlife & heritage value |
|:--:|---|---|---|---|
| ☐ | Japanese beech | <span class="latin">Fagus crenata</span> | Ridges & upper slopes | Beechmast feeds bear & boar; climax-forest indicator |
| ☐ | Mizunara oak | <span class="latin">Quercus crispula</span> | Moist mid–upper slopes | Acorns are key bear forage |
| ☐ | Konara oak | <span class="latin">Quercus serrata</span> | Satoyama secondary woods | Acorns, charcoal, shiitake logs |
| ☐ | Sawtooth oak | <span class="latin">Quercus acutissima</span> | Lower sunny slopes | Acorns, sap draws beetles |
| ☐ | Horse chestnut | <span class="latin">Aesculus turbinata</span> | Streamsides & valleys | Giant old trees; seeds → tochi-mochi |
| ☐ | Japanese nutmeg-yew | <span class="latin">Torreya nucifera</span> | Shrine groves, slopes | Sacred, slow-growing, edible seed |
| ☐ | Wild mountain cherry | <span class="latin">Cerasus jamasakura</span> | Mixed slopes | Spring bloom; birds eat fruit |
| ☐ | Japanese maple | <span class="latin">Acer palmatum</span> | Valleys, understory | Autumn color, high biodiversity |
| ☐ | Bigleaf magnolia | <span class="latin">Magnolia obovata</span> | Moist slopes | Large flowers feed pollinators |
| ☐ | Japanese zelkova | <span class="latin">Zelkova serrata</span> | Valley floors, village edge | Large heritage shade trees |
| ☐ | Japanese chestnut | <span class="latin">Castanea crenata</span> | Sunny satoyama slopes | Nuts feed people & wildlife |
| ☐ | Katsura | <span class="latin">Cercidiphyllum japonicum</span> | Streamsides | Giant old trees, fragrant autumn |

**Note** — Sugi & hinoki plantation conifers are *not* survey targets; this project replants **native broadleaf** for wildlife forage. Record sugi only if it is an exceptional old/heritage specimen. **How to measure** — DBH = trunk diameter at 1.3 m height. A "mother tree" is an old, healthy, abundantly seed-bearing tree worth protecting as a seed source.

# 御杖村 母樹・郷土樹 野外調査ガイド

**目的** — 御杖村の在来「母樹」（野生動物の餌となり、次世代の森を育てる老齢広葉樹）を見つけ・同定し・記録する野外ツールです。

## 在来樹種チェックリスト

| ✔ | 日本語名 | 学名 | 生育環境 | 価値（野生動物・郷土） |
|:--:|---|---|---|---|
| ☐ | ブナ | <span class="latin">Fagus crenata</span> | 尾根・上部斜面 | 堅果は熊・猪の餌、極相林の指標 |
| ☐ | ミズナラ | <span class="latin">Quercus crispula</span> | 湿った中〜上部斜面 | どんぐりは熊の重要な餌 |
| ☐ | コナラ | <span class="latin">Quercus serrata</span> | 里山二次林 | どんぐり・炭・椎茸原木 |
| ☐ | クヌギ | <span class="latin">Quercus acutissima</span> | 日当たりの良い下部斜面 | どんぐり、樹液に昆虫 |
| ☐ | トチノキ | <span class="latin">Aesculus turbinata</span> | 沢沿い・谷 | 巨木、栃餅の文化 |
| ☐ | カヤ | <span class="latin">Torreya nucifera</span> | 社叢・斜面 | 神木、希少、食用の実 |
| ☐ | ヤマザクラ | <span class="latin">Cerasus jamasakura</span> | 混交林の斜面 | 春の花、果実は鳥の餌 |
| ☐ | イロハモミジ | <span class="latin">Acer palmatum</span> | 谷・林床 | 紅葉、生物多様性 |
| ☐ | ホオノキ | <span class="latin">Magnolia obovata</span> | 湿潤斜面 | 大きな花、送粉者 |
| ☐ | ケヤキ | <span class="latin">Zelkova serrata</span> | 谷底・集落縁 | 巨樹・里の象徴木 |
| ☐ | クリ | <span class="latin">Castanea crenata</span> | 日当たり里山斜面 | 実は人と動物の食料 |
| ☐ | カツラ | <span class="latin">Cercidiphyllum japonicum</span> | 沢沿い | 巨木、秋に甘い香り |

**注** — スギ・ヒノキの人工林は調査対象外。本事業は野生動物の餌となる**在来広葉樹**を植え戻します。スギは特に古い名木の場合のみ記録。**測定方法** — 胸高直径(DBH)は地上1.3mで測定。母樹＝種子源として保全すべき健全な老齢結実木。
