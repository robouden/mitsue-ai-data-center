## 1. プロジェクトの概要

奈良県御杖村(人口約1,400人、森林率約93%)では、戦後に植えられた杉の人工林の多くが、50〜75年生となった今も手入れされていません。ボトルネックは土地や需要ではなく**林業の担い手**です。

本プロジェクトは、村・地元の林業組合・NGO(モア・トゥリーズ)と協力する独立した取り組みで、次の三つを一体で進めます。

- **森林再生** ― 間伐材を搬出し、伐採跡地には在来広葉樹を植え戻す(杉の単一林からの転換)
- **バイオマスCHP** ― 間伐材のチップを燃料とする熱電併給(まず50 kWeのプロトタイプ)
- **AIデータセンター** ― 24時間安定した電力と熱を使う需要家(将来的に本格規模)

CTL(短幹材)機械は、このうち森林から木材を搬出する部分の鍵であり、少人数の作業班でも必要な規模の間伐・搬出を可能にします。

## 2. フェーズと時期

| フェーズ | 時期(目標) | 主な内容 |
|---|---|---|
| 0. 準備期 | 2026年4月〜12月 | 地域の信頼構築、創設チーム形成、設置場所・燃料の協議 |
| 1. 基盤期 | 2027年1月〜8月 | 法人設立、フィージビリティスタディ |
| 2. 試行設計期 | 2027年8月〜2028年8月 | 詳細設計、提携、許認可 |
| 3. 試行構築期 | 2028年8月〜2030年2月 | 小規模な初期段階の建設 |
| 4. 運営・拡大期 | 2030年2月以降 | 運営、モニタリング、拡張 |

**CTL機械の試験導入について:** 現実的な時期は**2028年初め**(2027年度末)と考えています。これは上表のフェーズ2にあたり、その前にフェーズ1で燃料分析・機種選定・設置場所の合意を進めます。

**近い将来の道筋(10月12日にお伝えした内容と同じです):**

1. **まず**、地元林業拠点に50 kWeのCHPプロトタイプ(20フィートコンテナ)を設置。想定地は林業組合の土場ですが、未確定です。
2. **約1年以内に**、約50 kWの小規模なAI計算負荷を追加(設置場所は未定)。
3. **その後**、約1.2 MWe(2 × 0.6 MWe)のCHPと本格的なAIデータセンター。時期は未定です。

## 3. 現状

- 現在は**フェーズ0**(計画初期)です。
- **契約・購入・資金の確約はありません。** 上記の時期は目標であり、約束ではありません。
- フェーズ0は、地域との対話と体制づくりに時間をかけるため、2026年12月まで延長しました(フェーズ1以降は約3か月後ろ倒し)。

## 4. コマツ様との連携案

1. **まず試験導入** ― 御杖村をCTLプログラムの追加の試験・訓練の場として。傾斜・アクセス・搬出の所見を共有し、地元オペレーターの育成に協力します。
2. **購入・リースは後で** ― 試験で適合が確認でき、資金の手当てがついた場合に限ります(現時点でいずれも未確約)。
3. **共有できる物語** ― 国産林業機械が、広葉樹の植林・地域バイオマスエネルギー・村の活性化を支える事例。他の村へのひな形にもなります。
