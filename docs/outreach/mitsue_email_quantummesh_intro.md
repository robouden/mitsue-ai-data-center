# Introduction Email — Quantum Mesh Inc.

**Purpose:** First-touch request for an introductory call with Quantum Mesh (Quantum Mesh 株式会社) about their KAMUI immersion-cooling micro data centers, and whether the Takahama Town model could translate to Mitsue Village. Karsten Klein (AI data center governance/security consultant, recently joined as an advisor) is named as someone who could join a technical follow-up call.

See [[project_quantum_mesh_outreach|docs/outreach/mitsue_quantum_mesh_outreach.md]] for the full evaluation and action items this draws on.

---

## How to approach Quantum Mesh

No named contact has been confirmed yet (see open action item in the outreach evaluation doc) — a warm intro via 8M Capital or the Takahama Town agreement is still preferable if one turns up before sending. Absent that, this draft is written for the company's official contact form:

- Japanese: https://quantummesh.jp/contact
- English: https://quantummesh.jp/en/contact

(confirmed 2026-08-31 via the site's sitemap — the site is a JS-rendered SPA so these aren't visible by browsing normally, but both routes exist). Send the Japanese form as the primary contact, following the same rules used for HIGHRESO:

1. **Japanese first** — a Japanese company, Japanese rural project.
2. **No partnership ask yet** — request a short introductory call only.
3. **Show homework** — reference KAMUI γ, the PUE 1.03–1.04 figure, and the Takahama Town precedent specifically, not generic interest.
4. **Mention Karsten only as a name to know, not a decision-maker to defer to** — he is a recently-joined advisor (AI data center governance/security), available for a technical follow-up call if useful; this is Phase 0, no commitments exist yet.

### What to expect

- 1–4 week response window is normal.
- Do not attach full project documentation on first contact; if asked, send the English/Japanese README + introduction A4.

**Subject:** KAMUIシリーズに関するご相談 ― 御杖村プロジェクトより

---

Quantum Mesh株式会社
ご担当者様

貴社のKAMUIシリーズ（液浸冷却型マイクロデータセンター）に関する取り組みを拝見し、私どもが奈良県御杖村で進めている小規模AIデータセンター構想にとって、大変参考になる、また将来的な協業先となり得る企業と考え、ご連絡差し上げます。

オランダ出身で、現在奈良県御杖村において、バイオマス発電とAIデータセンターを核とした地域再生プロジェクトを準備しております、Rob Oudendijk（ロブ・アウデンダイク）と申します。

特に、**KAMUI γ**（1m²未満のオールインワン型マイクロデータセンター）と、**PUE 1.03〜1.04**を実現する液浸冷却の効率性、そして福井県高浜町での自治体連携によるデータセンター展開の事例に強い関心を持っております。御杖村で進める私どものプロジェクトも、規模は小さいながら同じ方向性を目指しております。

**御杖村プロジェクトの概要（簡略）:**
- 村内に整備予定の小規模AI／エッジコンピューティング・データセンター（設置場所は、旧木造校舎、御杖体験交流館（こうりゅうかん）、遊休工場施設などを候補に現在選定中）
- バイオマスCHP（熱電併給）を主電源とする24時間稼働の地産地消型エネルギー設計
- 25年スケールの森林再生・林業再活性化を並行して推進
- 御杖村が環境省補助で策定した公式の再エネ導入最大化計画（2025年）の実行主体という位置づけ

なお、直近でAIデータセンターの governance・セキュリティ分野の顧問として Karsten Klein 氏（KLEIN K.K. Advisory Services Japan 代表、元Nomura/Lehman/UBSのリスク・統制インフラ責任者）にプロジェクトへご参加いただいております。技術的な詳細に踏み込む段階になりましたら、同氏に面談へ同席いただくことも可能です。

ご多忙のところ恐縮ではございますが、ご一考いただけますと幸いです。
