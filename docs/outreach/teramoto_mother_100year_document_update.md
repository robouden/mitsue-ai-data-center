# 寺本様

先日は、貴重な「百年構想」の資料をお貸しいただき、誠にありがとうございました。おかげさまで、資料についていくつか新しいことがわかりましたので、ご報告かたがたお便りを差し上げます。

資料の中の「林野行政」と題する論考を書かれた方が、どなたであるかがわかりました。三重県多気郡大台町にある自然宗佛國寺のご住職、黙雷和尚という方です。もともとは鹿児島にお寺があったのですが、その後、大台町に移転されていたため、探し出すのに少し時間がかかりました。

現在は、黙雷和尚に代わってお便りをくださっている、薬師庵主の釈妙円様という方とやり取りをさせていただいております。黙雷和尚は、この20年間、「いのちの森」という文章を書き続けてこられたそうで、その内容を近くお送りいただけることになりました。

また、面白い偶然もわかりました。お寺のある大台町は、私どもが森林再生でご一緒しているmore trees（モア・トゥリーズ）というNGOが、宮川森林組合様と2022年から提携している場所と、同じ町だったのです。世の中は、思いがけないところでつながっているものだと、あらためて感じております。

もし機会がございましたら、一度お寺にお伺いし、妙円様や黙雷和尚に直接お目にかかりたいと考えております。

貴重な資料をお貸しいただいたおかげで、このように多くのことがつながりました。あらためて、心より御礼申し上げます。

オウデンダイク・ロブ
