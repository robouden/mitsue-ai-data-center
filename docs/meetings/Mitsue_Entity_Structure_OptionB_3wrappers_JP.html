資金の流れ How value moves
流れ内容
所有者 → 組合 私有林所有者が協同組合に加入し、細分化した区画を1つの交渉可能な供給ブロックに集約。組合員は燃料材・地代収益を持分比で分配——非営利が法的に提供できない利益の分け前。
組合 → 燃料 組合が既存 牛峠工場で間伐材を破砕・乾燥。補助金活用の燃料規格チッパー（P31S–P45、20%未満）を組合所有。チッパー規格・乾燥は要確認。
組合 → 事業会社 燃料材は長期オフテイク契約（数量・価格固定）で事業会社へ販売——CHPの返済能力を支える供給安定。
CHP → 計算 熱・電力でデータセンターを稼働。余剰電力は温泉／村へPPA可能。
収益 → 使命 営業余剰は「収穫が再植林を賄う循環」として非営利へ還流。
補助金 DC／電力（METI GX地域共創、環境省ゼロエミッション）→ 事業会社；森林／RE交付金 → 非営利；チッパー・林業補助 → 組合。
みずほの金融 社債／SLL／出資は事業会社へ、助成・インパクト助言は非営利へ、組合が供給を固める。
上坂様への問い
「森林の多くが私有のため、区画を束ね、事業会社へ燃料材を契約供給する組合員所有の協同組合を検討しています。金融の観点から——協同組合の供給層は、融資／SLL組成の際に事業会社の燃料供給安定・担保・Jクレジット帰属を強化しますか、それとも複雑化させますか。組合員の紐帯よりも、長期オフテイク契約で供給を固める方が望ましいでしょうか。」
トレードオフ: 第3の法人は所有問題（私有地≠コモンズ）を解決する一方、貸し手が割り引く法人間契約が増えます。上坂様は新法人より契約供給を選好する可能性——その場合、案A＋供給契約が案Bに勝ります。
