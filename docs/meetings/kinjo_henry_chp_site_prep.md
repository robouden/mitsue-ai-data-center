# Prep Note — Kinjo + Henry Meeting: Prototype CHP + AI DC Site

**Attendees:** Kinjo Rie (近処里英, Mitsue Village Forest Cooperative), Henry Takata (advisor, biomass CHP biz-dev), Rob
**Trigger:** Kinjo mentioned a possible site for a prototype <50kWe CHP + AI data center in a recent meeting — not yet a firm offer.
**Goal of this meeting:** Turn the informal mention into a concrete go/no-go read on feasibility. Not a commitment meeting.

## Site Basics to Confirm

1. **Land status**
   - Who owns/controls the site — Kinjo personally, the Forest Cooperative, or the village?
   - Any existing use, lease, or zoning restriction?
   - Is it available for a multi-year pilot, or short-term only?

2. **Grid access**
   - Distance to nearest substation/feeder (compare against known bottleneck: 掛変電所 6.6kV, 3MW local cap).
   - Existing grid connection at the site already, or new hookup needed?
   - Any FIT/FIP implications if CHP >50kWe is ever considered later (current plan is sub-50kWe pilot, so likely exempt).

3. **Footprint**
   - Available land area (rough dimensions) for CHP unit + fuel storage/chipping + DC container/rack space.
   - Access for delivery trucks (fuel supply, equipment installation).
   - Proximity to fuel source — is this near existing chip/dry infrastructure (牛峠工場) or would it need its own?

4. **Timeline**
   - How soon could site access start (permitting, any construction/prep needed)?
   - Kinjo's/Henry's sense of realistic pilot timeline (design → install → commissioning).
   - Any dependency on other pending items (e.g., FY2026 subsidy tracks, GX地域共創 inquiry outcome)?

## Secondary Questions (if time allows)

- Does the site support a domestic-maker CHP unit (中外炉/神鋼/静岡製機/ネオナイト) in terms of space/power requirements?
- Could this double as a resilience/disaster node (like the 姫石の湯 concept), or is it purely a technical pilot?
- Who would operate/maintain the CHP day-to-day — Cooperative staff, a contractor, or a new hire?

## Not to raise yet

- Don't present this as a secured site to any third party (village hall, funders) until land status and grid access are confirmed here.
- Keep scope framed as "pilot/prototype," not full-scale deployment — avoids overstating readiness ([[feedback_outreach_overstatement_risk]]).
