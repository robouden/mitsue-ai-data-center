# Reference: Komatsu PC138 (C93 head) vs 901XC (+ winch) on Steep Terrain

- **Source:** AI search-assistant answer pasted by Rob, 2026-11-08. **Unverified** — no primary Komatsu documents checked.
- **Caveats:** the answer calls the 901XC "Komatsu / Ponsse"; Ponsse is a different maker (the 901XC is Komatsu Forest). Weights, slope %, winch cable lengths (300–500 m) are the assistant's figures, not confirmed. Verify with Komatsu before use.

## 1. Komatsu PC138 + C93 harvester head
- Short-tail-swing crawler excavator (~14–15.5 t) with Komatsu C93 head (3 feed rollers, tilt-up) on a folding bracket.
- **Pros:** tracks (500 mm grousers) grip hard soil/loose rock; low sideways-rollover risk; tight tail swing for strip thinning near banks/trees; can bench its own paths; strong hydraulic force.
- **Cons:** ground disturbance and track slip on wet clay; slow travel; no standard integrated winch (relies on track traction or an anchor machine).

## 2. Komatsu 901XC (8WD CTL harvester) + winch
- Dedicated 8-wheel-drive cut-to-length harvester (~20+ t), bogies (optional tracks), built for thinning on steep/soft ground.
- **Pros:** low ground pressure; automatic cab/crane leveling; with winch (T-Winch / Synchrowinch) can work steep slopes (claimed 35–55%+) with the cable carrying load.
- **Cons:** bulkier, less suited to tight micro-thinning in rocky/stumpy ground; higher center of gravity; without winch tether it can slide/tip sooner than a tracked excavator.

## Comparison
| Metric | PC138 + C93 | 901XC + winch |
|---|---|---|
| Base | Crawler excavator (~15.5 t) | 8WD wheeled harvester (~20+ t) |
| Traction | Crawler tracks | 8 wheels + optional tracks + cable winch |
| Slope method | Track climbing / benching | Tractive force + anchored winch |
| Tight thinning | Superior (short tail swing) | Good, needs wider aisles |
| Operator comfort on pitch | Standard cab | 4-way auto leveling |
| Best for | Rocky/broken/confined cuts | Long-reach thinning on soft/steep soil with winch |

## Does a winch reduce road construction? (answer: yes)
- Winch-tethered 901XC can run straight up/down the fall line, so no dense horizontal strip roads/benches needed.
- Cable reach (claimed 300–500 m) lets machines work from existing ridge-top or valley-bottom roads.
- Less soil disturbance, erosion and landslide risk than dense road networks.
- Winch-assisted forwarder (855/875) can extract logs along the same vertical tracks, avoiding intermediate landings.
- **Requirements:** anchor point at top (road, tree, stump, machine); work along the fall line only (sideways on steep slopes still unsafe); extreme cliffs/deep ravines still need tower yarding or benching.

## Cross-check: FFPRI (森林総合研究所) primary research, pulled 2026-11-08
Summary + files: `/home/rob/Documents/Mitsue/Mitsue Village Project AI data center/docs/reference/ffpri/README.md`
- **Slope threshold:** vehicle-based machines to ~15–20°; cable-based above (成果21, `seikasyu21.pdf`). Roughly consistent with the winch claims above (35–55% ≈ 19–29°) — i.e. the 901XC+winch occupies the band where cable systems normally take over.
- **Winch on harvesters is documented in Japan:** Kagoshima model forest used a winch-mounted harvester + forwarder to cut machine count (mid slopes, small–mid sites); all model forests ≥10 m³/person-day vs national thinning avg ~3 (`p38-39.pdf`, 2010).
- **Winch-grapple + dense skid roads** is the standard steep-slope adaptation of forwarder-type machines (成果21) — FFPRI does *not* support "winch removes the need for roads"; roads still raise applicability. Treat the "yes" in the section above as unconfirmed.
- **Tower yarder alt.:** ~1.5× productivity of swing yarder, needs high-grade forestry roads; earlier Japanese attempts failed (`p10-11.pdf`). Productivity: strip thinning 3.2 vs spot 2.0 m³/person-day (成果21).
- Still unverified: Komatsu-specific 901XC/PC138 figures.

## Rob's hypothesis: for large clear-cuts on steep ground, winched 931XC/901XC + winched 855 beat road-building (money and time)
**All figures marked (A) are Claude's placeholder assumptions, NOT verified quotes — replace with Komatsu / contractor numbers.** (S) = sourced from FFPRI (see above).

| Item | Road-based system (PC138 + C93, 作業道 benching, forwarder) | Winched 931XC/901XC + winched 855 |
|---|---|---|
| Road density needed | ~100–150 m/ha (A) | ~30–50 m/ha, ridge/valley access only (A) |
| Road cost (A: ¥2,000–4,000/m) | ~¥200–600k/ha | ~¥60–200k/ha |
| One-off winch cost | none | ~¥15–30M per machine, ×2 machines = ¥30–60M (A; ask Komatsu/Ritter/Synchrowinch) |
| Road-building time | Excavator weeks per site before harvest starts (A) | Little; start cutting almost at once (A) |
| Labor | Road crew (operator + helper) + harvest crew | Harvest crew only (operator ×2 + spotter) (A) |
| Soil disturbance / landslide risk | Higher (benching, cuts, fills) | Lower; fall-line tracks only |
| System productivity | Tower-yarder system clear-cut 4.1 m³/person-day (S, seikasyu21); national clear-cut avg 5 (S, p38-39) | 10–20 m³/person-day reached by FFPRI high-performance model forests on mid slopes (S, p38-39); steep+winch figure unverified |
| Area cleared / day (at ~300 m³/ha, 3-person crew) (A) | ~0.05–0.1 ha | ~0.1–0.2 ha |
| Best case | Rocky/broken ground, tight strip thinning | Long fall-line slopes, soft soil, large volumes |

**Break-even sketch (A):** winch kits ¥30–60M ÷ road saving ¥140–400k/ha ≈ **75–430 ha**. Komatsu's "30,000 m³/yr minimum" (per 931XC, per 2026-11-03 follow-up) at ~300 m³/ha = ~100 ha/yr → payback in roughly **1–4 years** if the winch also lets you avoid the roads. Supports Rob's gut feeling at high volume; at small volume (<~20 ha/yr) road-based methods stay cheaper.

**Caveats:**
- FFPRI (成果21) says winch-grapple use goes *with* dense skid roads on steep ground; "hardly any roads" is from the videos/assistant, not a Japanese study. Verify.
- Winch work needs an anchor and runs along the fall line only; cliffs and deep ravines still need tower yarding or benching.
- 30,000 m³/yr per machine implies far higher output than the m³/person-day figures above; ask Komatsu what basis (stumpage vs delivered logs) that number uses.
