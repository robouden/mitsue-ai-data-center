# 御杖村森林組合——担い手確保・移住戦略

> **「山を再生し、AIデータセンターを動かし、村を再建する——ひとつの仕事、ひとつの場所、25年の物語。」**

御杖村森林組合（Mitsue Kanko）の作業員を倍増（将来的に3倍）することが、森林→エネルギー
計画全体を可能にする唯一のレバーです（`mitsue_forest_workforce_energy_plan_jp.md` 参照）。
本書は、日本の既存の林業・移住支援制度を活用し、**使命を第一に、資金をその後押しとして**
適切な人材を惹きつける方法を示します。

中核となる考え：**補助金は「並び」に到達させ、使命こそが実際に人を惹きつけ、定着させる。**
補助金は移住しない金銭的理由をすべて取り除き、使命は移住する理由となる——そしてそれが、
移住制度で知られる「3年定着問題」の解決策です。

---

## 1. 引きつける力（プル）——3本柱の使命

ありふれた地方林業の売り込み（「過疎の村で杉の間伐を」）は難しい。私たちの提案は根本的に
異なります。同じ仕事が、森を再生し、計算資源を動かし、村を蘇らせる。各柱が異なる層に届きます。

### 🌱 再生（Reforest）——生きた在来林を取り戻す
「木を切る」のではなくその逆：**暗く生命の乏しい杉一斉林を、生きた在来広葉樹林へ転換する**
——コナラ・クヌギで野生動物の餌を確保し、鳥・昆虫・生態系の均衡を取り戻し、水源を守り
土砂災害リスクを下げる。**実際に歩いて確かめられる数十年の遺産**です——*先人が木材のために
植えた森を、子孫に遺す森へ*。これが感情の核であり、「林業作業員」の求人には決して応じないが
*山を再野生化する*ためなら移住する **自然保護・生態系志向の人々** を惹きつけます。

### ⚡ 動力（Power）——エネルギーと村営AIデータセンター
同じ森の仕事が **計算資源を文字どおり動かす**——バイオマスCHP、ソルトバッテリー蓄熱、
村営データセンター。アナログな林業ではなく最先端。**目的志向の技術者・エンジニア** を惹きつけます。

### 🏡 再建（Revive）——未来のある村を取り戻す
過疎の山村に本物の次章を——雇用、家族、エネルギー自給、防災。郷愁ではなく *未来のある*
地方生活を求める **UIターン移住者** を惹きつけます。

**3本柱が重要な理由：** これはプロジェクトの全論旨をひとつの仕事に凝縮したものです——
*森林再生 → 分散型エネルギー → 地域所有の計算資源*。多くの地方の仕事は1本の糸しか提供
しませんが、これは3本を編み合わせて提供します。その幅こそが、魅力であり定着の接着剤です。

## 2. 誰を採用するか（ペルソナ）

| ペルソナ | 惹かれる柱 | 届け方 |
|---|---|---|
| **自然保護・生態系志向（20〜40代）** | 再生——再野生化、生物多様性 | 自然保護NGO、再野生化コミュニティ、生態学系 |
| **目的志向の技術者・エンジニア（20〜30代）** | 動力——エネルギー＋データセンター；都市疲れ | 気候テックコミュニティ、プロジェクトの人脈（Ray Ozzie / Joi Ito）、メディア |
| **UIターン移住者・若い家族** | 再建——未来のある地方生活 | 移住フェア、JOIN、県の移住ポータル |
| **林業＋情報工学の学生** | 3本柱の稀な交差点 | 大学の林学・CS学科、インターン |

これらの人々は「森林組合作業員」の求人を見ていません。正式な求人掲載は（補助金要件のため）
必要ですが、実際の到達は、コミュニティとメディアを通じた使命の物語です。

## 3. スタック——支援制度（2026年、確認済み）

| 制度 | 資金元 → 受給者 | 金額 | 役割 |
|---|---|---|---|
| **緑の雇用** | 林野庁 → **組合** | 新規就業者の人件費相当＋OJT研修助成（約3年フォレストワーカー） | **中核レバー**——未経験者採用の費用・リスクを除去 |
| **地域おこし協力隊** | 総務省（特別交付税）→ **御杖村** 経由 | 報償費 約320万円/年＋活動費 約200万円/年（計約520万円）、最長3年；＋起業支援 最大100万円 | 約3年の助成付ポスト→常勤採用へ転換 |
| **移住支援金** | 国＋県＋町 → **移住者** | 世帯 最大100万円＋18歳未満の子1人あたり最大100万円；単身60万円 | 東京23区→御杖、登録された組合の仕事に就く移住者向け |
| **緑の青年就業準備給付金** | 林野庁 → 就業準備者 | 研修中 最大 約155万円/年 | 林業学校からの供給パイプライン |
| **空き家バンク＋村の住宅支援** | 御杖村 | 空き家マッチング＋改修支援 | 移住の住居面を解決 |
| **プロジェクト上乗せ** | プロジェクト（エネルギー収益／環境省交付金） | 一時金、改修、家族支援 | 他村との差別化 |

### 積み上げパッケージ例——移住する一家族

**地域おこし協力隊（約520万円/年 × 3年）** もしくは **組合直接雇用＋緑の雇用 研修助成**
→ **さらに 移住支援金 100万円＋子1人100万円** → **さらに 空き家住宅＋プロジェクト上乗せ。**
真に競争力あるパッケージであり、協力隊の任期後には常勤の森林組合の仕事が待っています
（多くの村に欠ける定着の要）。

## 4. 必要な準備——実施アクション（フェーズ0〜1）

1. **森林組合が「緑の雇用」実施事業体として登録** し、奈良県のマッチングサイトに求人掲載。
   *緑の雇用と移住支援金の両方の要件を解錠。* — 担当：組合＋プロジェクト。
2. **御杖村が地域おこし協力隊のポストを新設**（林業＋CHP/チップ運用＋樹木調査/エコツーリズム
   を束ねる）。*村長・村の決定——官民連携に直結。* — 担当：代表理事＋村。
3. **御杖村／奈良県の移住支援金参加とマッチングサイト掲載を確認。** — 担当：プロジェクト＋村。
4. **職務を多技能で設計**（林業＋エネルギー＋現場技術）——魅力と定着に不可欠。
5. **使命の物語の到達を構築**：ランディングページ、メディア切り口、プロジェクト人脈と
   気候テック／自然保護コミュニティへの働きかけ。

---

## 5. 率直な留意点

- **協力隊の3年定着は全国的な弱点。** 解決策は任期後に待つ常勤の仕事と事業モデル——本
  プロジェクトが提供するもの。受け皿なしにポストを作らないこと。
- **移住支援金には返還条項**（約5年以内の転出）——正直に期待値を設定。
- **職務は多技能であること。** 杉の間伐だけでは若い家族は定着しない；再生＋エネルギー＋技術の
  幅が人を留める。
- **使命は本物であること（見せかけ厳禁）。** これらの層はグリーンウォッシュを瞬時に見抜く——
  再生は燃料目的ではなく在来生態系を真に優先すること（`project_reforestation_principle` 参照）。
