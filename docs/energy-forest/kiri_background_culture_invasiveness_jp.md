# 桐(キリ)— 文化的価値・国産材の減少・侵略性

**位置づけ:** SANSEI(山内様)の桐植林計画の参考情報。米国の動画2本の書き起こしと、確認できた出典を整理。方針ではなく、山内様のご判断を尊重する。本プロジェクトでの主用途はバイオマス燃料であり、用材価値は可能性にとどまる。英語版: `kiri_background_culture_invasiveness.md`

---

## 1. 文化的価値

- 長寿・繁栄の象徴。桐たんす、琴、下駄、祝い膳など。気密性・調湿性に優れる。([中川政七商店](https://story.nakagawa-masashichi.jp/106795)、[桐たんす.com](https://www.tansu.com/kiri/))
- 文化財を維持する特用林産物。([日特振](https://nittokusin.jp/bunkazai_iji/kiri/))

## 2. 国産材の減少(動画の主張の確認)

| 動画の主張 | 確認結果 |
|---|---|
| 原産地でほぼ絶滅 | **誇張。** 国産桐の生産量は昭和34年(1959年)がピークで、現在はその約2%。生活様式の変化とてんぐ巣病が要因。木が絶滅したのではなく国内供給が激減。 |
| 病原体 | てんぐ巣病はファイトプラズマが原因で、カメムシ類・ヨコバイ類が媒介。東アジアで最も深刻な桐の病害(中国で88万ha、2008年)。([総説](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11123829/)) |
| 輸入依存 | 1972年頃から中国産、のち米国産。ある販売サイトは財務省統計で約95%輸入と記載(**未確認。貿易統計で要確認**)。 |
| 丸太が高値 | 動画の逸話のみ。価格データは見つからず。**数値は引用しない。** 会津桐は病気に強い苗木で再興の動き。([日経](https://www.nikkei.com/article/DGXZQOCC14D2F0U1A211C2000000/)) |
| 日本原産 | 一般に**原産は中国**とされ、日本では古くから栽培。「日本原産」とは書かない。 |

主な国内産地:会津(福島)、秋田、南部(岩手)、群馬、津南(新潟)。

## 3. 侵略性(米国)と植栽上の注意

- *Paulownia tomentosa* は米国農務省と多くの州で侵略的外来種。1840年に導入。([Bugwood/USFS](https://wiki.bugwood.org/Archive:IPSF/Paulownia_tomentosa))
- 1蒴果に約2,000粒の有翅種子、1本で年約2,100万粒。風・水で拡散(山地で最大約3km)。火災・伐採などの攪乱後に侵入。
- 御杖村: 日本ではすでに帰化。日本での規制状況は**未確認**。SANSEIへの留意点として、結実前の伐採、河川沿い・攪乱地への植栽回避を推奨。

### 3b. 2本目の動画(World Tree社の宣伝)

販売業者の主張であり中立な出典ではない。

- 「*tomentosa*のみ侵略的」: 妥当そうだが**未確認**。品種ごとに苗木業者へ不稔性を確認。
- 「9年試験で生存率27.3%、だから侵略的でない」: 試験は実在(Berg他, 米国森林局, アパラチア南部。[TreeSearch](https://research.fs.usda.gov/treesearch/60846))。ただし低生存率は**悪天候**が原因で、植栽木の生存を見たもの。**種子拡散や侵略性の証拠にはならない。引用しない。**
- 「窒素固定」: 疑わしい(桐は窒素固定植物として知られない)。繰り返さない。
- 蜜源・重金属浄化: あり得るが未確認。
