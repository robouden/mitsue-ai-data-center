# 桐(キリ)・スギ・ヒノキの比較 — 生材含水率と乾燥

目的: SANSEI の桐に関する打ち合わせ(2026-10-22)と燃料供給計画のための、第一次の比較整理。(英語版 v1.5 の日本語訳) **文献調査のみ。御杖村での実測値はない。日本産の桐の生材含水率の数値は見つからなかった。**

含水率(MC)の表記: 特記がない限り**湿量基準**(水分 ÷ 全質量)。換算式: 湿量基準% = d ÷ (1 + d)(d = 乾量基準含水率を小数で表したもの)。

## 2. 燃料としての意味

- **ガス化炉の許容含水率**(燃料需要の資料より): Volter 15%以下、Entrenco 12%以下、ESPE 45%以下、Esperia 40%以下。含水率約60%の桐の生材は、どの機種でも乾燥が必要。
- **製材のデータでは、桐はスギより乾燥が速い**。ただし、比較しているのは桐は製材、スギは土場の丸太であり、**同じ条件での比較ではない**。
- **約45%までの乾燥が確認されているのはスギだけ**: 葉枯らし+日当たり・風通しの良い土場で約4か月。林内の土場では丸太はほとんど乾かなかった。
- **桐の梢部や葉は幹よりずっと湿っている**。桐を一度にまとめて収穫する場合(SANSEI の計画では5年目)、収穫量全体に見合う貯蔵と乾燥の能力が必要になる。
- 含水率50% → 15%の乾燥に必要な熱は、乾燥木材1トンあたり約2.0 GJ(損失を除いてCHPの熱の約30%)(燃料需要の資料より)。含水率約60%の桐では、さらに多く必要。

### 2b. エネルギーと重量: 結論

- **乾燥重量1 kgあたりでは、桐はスギと同等ではなく、やや低い。** 同じ研究室の熱量計での測定(栃木の論文、表5): 桐の木部 18.9 MJ/kg、スギ 20.2 MJ/kg(約6%低い)。他の桐の研究では 16.7〜19.7 MJ/kg の幅があるため、「ほぼ同じ」という従来のメモは、その幅の中でのみ正しい。
- **桐の1 m³あたりの重量は軽い。** 研究により乾燥で231〜335 kg/m³。日本の4年生の桐では、根元で209 kg/m³、根元から梢までの平均で255 kg/m³、スギは302 kg/m³だった。桐の強みは密度ではなく成長の速さ。
- **生材の重量の大半は水。** 含水率約60%では、樹種を問わず、生材1トンに含まれる乾燥木材は約0.4トンだけ。運搬と乾燥のコストには、樹種より含水率の影響が大きい。
- **専門家の見解(杉本和也氏、天川村、2026-10-15、個人の意見):** 桐の木部は密度が非常に低いため、エネルギーが小さく、バイオマスには不向きと考えている。栃木の論文も、1 m³あたりの点では同じ結果(4.0 GJ/m³、スギは6.1 GJ/m³)。1 MWhあたりの運搬・取り扱い・貯蔵の量が増える。
- **桐とスギの直接比較(根津ほか、BioEnergy Research 19:6、2026年。全文を確認。NEDO の資金による。コピーは docs/energy-forest/source-scans/s12155-025-10943-8.pdf)。** 栃木県益子町の4年生のパウロニア15本。2020年7月に3×3 mで、**平坦な耕作放棄地に植栽し、毎年の施肥・下刈り・病害虫防除・枝打ちを実施**。幹の平均は直径15.6 cm、樹高9.7 m、1本あたり0.0828 m³。日本の9樹種と比較(表5、6、7):

  | | パウロニア(4年生) | スギ |
  |---|---|---|
  | 総発熱量(木部) | 18.9 MJ/kg | 20.2 MJ/kg |
  | 基本密度(全乾重量/生材体積) | 209 kg/m³(幹の平均 255) | 302 kg/m³ |
  | 木材1 m³あたりのエネルギー | **4.0 GJ/m³(10樹種中で最低。スギの66%)** | 6.1 GJ/m³ |
  | 灰分(木部) | **1.7%(JWBA チップ区分3)** | 0.4%(区分1) |
  | 灰分(樹皮) | 4.5%(区分4) | 0.5% |
  | カリウム | 木部 0.4%、樹皮 1.5%(クリンカーのリスク) | 未測定 |
  | 生材の含水率(湿量基準) | 平均58.2%。根元 70.5%から梢 47.6%まで | 論文に記載なし |
  | 1 haあたりの年間収量 | 4.9 t/ha/年、93 GJ/ha/年(幹全体) | 5.0 t/ha/年、101 GJ/ha/年(48年生の林分) |

  著者らの結論: 1 m³あたりでは、試験した中で桐が最も燃料に向かないが、1 haあたり・年あたりでは、成長が速いためスギとほぼ同等であり、短伐期なら成り立ちうる。JWBA の区分では、含水率55%超のチップは不適とされるため乾燥が必要であること、幹の上部の木材は乾いていること、幹の下部を製材に回せば乾燥コストが下がることも述べている。**御杖村への留意点:** 1 haあたりの数値は、平均的な15本 × 1 haあたり1,055本から外挿したもので、管理された平坦な農地、シカなし、急斜面なしの条件。スギの比較対象は48年生の林分。1か所、1つの樹齢のみ。元口の丸太を製材に回すと、幹全体の収量は 47 GJ/ha/年に下がる。
- **クロアチアの研究(Vusić ほか、GREEN 2018、ザグレブ大学林学部):** 交雑3種(9501、Shang Tong、OXI)。生材含水率 62.4 ± 1.7%、基本密度 335 ± 27 kg/m³。木部と樹皮の灰分、CHNS、発熱量も測定。スギとの比較はない。出典: [CROSBI 947148](https://www.bib.irb.hr/947148)。上記の19.3 MJ/kgは再確認していない。
- **灰分:** 栃木 1.7%(木部)対 スギ 0.4%(同じ方法、同じ論文)。他の桐の研究: 0.4%(COTEVISA-2、Springer 2024)、0.89%(三元交雑種)。灰分とカリウムはガス化炉では重要。直接比較の1件では、桐の灰分はスギより多い。
- **見つかっていないもの:** 同一の場所での桐とスギの直接比較、一次資料によるスギの乾燥密度、ヒノキの密度。桐の梢部・葉は灰分と含水率の負荷が高い(未測定)。

**栽培上の注意:** 桐は霜に弱く、クマとシカへの十分な対策が必要。スギとヒノキは地域に根づいた樹種で、御杖村では霜による制約はない。桐とスギの燃料コストを比べる際は、防護のコストも含めるべき。

## 3. 不明な点 — 測定または確認したいこと

1. **京都皇帝早生桐**の幹の生材含水率(5年生と7年生)。(10/22に SANSEI に確認。データをお持ちかもしれない)
2. ヒノキの生材含水率(数値は見つからず。ヒノキはここでは優先的な燃料ではない)。
3. 御杖村の気象条件での、桐のチップ・丸太の乾燥期間。(鳥取の4か月はスギにのみ当てはまる)
4. **桐のガス化(2026-10-15に英語・日本語で調査): パウロニア/桐のガス化炉での試験は見つからなかった。** あるのは、実験室での性状(上記)、パウロニア材の低速熱分解(Yorgun & Yıldız 2015、J. Anal. Appl. Pyrolysis。773 Kで最大転化率77.4%、液体54 wt%)、査読されていないグリーンメタノールの構想記事のみ。パウロニアの灰の融点データはない。ダウンドラフト式ガス化炉でのリスク(カリウムの多い灰によるスラッグ化、低い嵩密度による供給不良・ブリッジング、含水率約58%)は、一般的なバイオマスガス化と栃木の論文からの推測であり、桐での試験ではない。CHPメーカー(Volter、Entrenco、ESPE など)と、樹種ごとにダウンドラフト式ガス化炉で試験している北海道の林産試験場に、桐を試した経験があるか尋ねる。
5. 地元のスギ丸太数本での、全乾法による含水率試験(EN ISO 18134-2 の方法)。基準値を得るため、今のうちに実施。
