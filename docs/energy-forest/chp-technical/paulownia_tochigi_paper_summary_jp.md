## 1. 何を調べたか

- 栃木県益子町の耕作放棄地(0.89 ha)に2020年7月、3×3 mの間隔で桐を植栽。毎年、施肥・下刈り・病害虫防除・枝打ちを実施(原文 Materials and Methods)。
- 4年生の15本(胸高直径15.6±1.2 cm、樹高9.7±0.8 m)の幹の体積、重さ、含水率、密度、化学成分、発熱量、元素を測定。
- 比較のため、日本の9樹種(スギ、ヒノキ、カラマツ、アカマツ、コナラ、ヤマザクラ、クリ、ホオノキ、キリ)の発熱量と灰分も測定(原文 Table 5, 6)。

## 2. 主な結果

| 容積密度(全乾重量/生材体積) | 209 kg/m³(幹の平均は255) | 302 kg/m³ | Table 5, Table 1 |

- 樹皮は木部より灰分・リグニン・発熱量が高い(原文 Table 2)。
- 日本木質バイオマスエネルギー協会の基準では、含水率55%超のチップは燃料に不適とされ、乾燥が必要(原文 Discussion)。灰分の等級では、木部は等級3、樹皮は等級4(原文 Discussion)。
- カリウムが多いため、燃焼炉でクリンカ(溶けて固まる灰)が生じやすい点に注意が必要(原文 Discussion)。

## 3. 著者らの結論

- 体積あたりの発熱量は最も低いが、成長が早いため、1ヘクタール当たりの年間エネルギー量はスギとほぼ同じ。短い伐期なら、燃料用として利用できる可能性がある(原文 Abstract, Concluding Remarks)。
- 幹の上部ほど含水率が低いため、下部を用材に、上部を燃料にすれば、乾燥のコストを減らせる(原文 Scenario 2, 3)。

## 4. 読むときの注意(Mitsue-itの見解)

- 調査地は平坦な耕作放棄地で、施肥と下刈りがあり、獣害や急斜面の条件はない。御杖村の山とは条件が異なる。
- 1ヘクタール当たりの値は、平均的な15本に1,055本/haを掛けた推定値。比較対象のスギは48年生の林(原文 Table 7 の注)。
- 調査地は1か所、樹齢は4年のみ。
- 本資料は、桐の単一樹種植栽についての私たちの調査の一部で、山内様のお考えを否定するものではありません。
