小規模な木質バイオマスエネルギー利用の採算性評価ツール（ガス化CHP ver.1.3およびバイオマスボイラーver.1.1）

Microsoft社の表計算ソフトExcelを利用して、木質バイオマスを用いた小規模なガス化熱電併給事業やバイオマスボイラーを用いた熱供給事業の採算性を評価するためのプログラムです。

用途

発電出力、設備導入費用、原料の種類・消費量・購入単価、熱利用の条件などを入力することによって、小規模なガス化方式の木質バイオマス熱電併給事業やバイオマスボイラーを用いた熱供給事業の採算性を評価できます。

利用方法

アンケートに回答いただいた方にプログラムを提供いたします。
アンケート用のファイルどちらかをダウンロードして回答してください。

ワードファイル（アンケート：20KB） PDFファイル（アンケート：235KB）
