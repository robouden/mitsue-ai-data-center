# 釈妙円（しゃく みょうえん） — 経歴メモ

自然宗佛國寺の薬師庵主・住持職であり、ロブの実際のメール連絡先（bukokuji@gmail.com）でもある
釈妙円さんについての調査資料。2026年10月の訪問に向けて作成。関連メモは
[[project_shaku_myoen_biography]]、[[project_mokurai_genmyo_kagoshima_temple]]（連絡の経緯）、
[[project_bukkokuji_visit_idea]]（訪問計画）、また寺院開山については
[mokurai_biography_ja.md](mokurai_biography_ja.md) を参照。寺院自身のサイト
（bukokuji.jimdofree.com の経歴紹介ページ）に加え、得度前の著作についてはCiNii・国立国会図書館
サーチ・楽天ブックス・東京都立図書館の各カタログという独立した書誌情報も参照した。経歴の物語
そのものは本人談・寺院側の情報であり、書誌情報はあくまで「旧名義で実在した著者である」ことの
独立した裏付けであって、物語の解釈自体を証明するものではない。

## 名前について

- **出生時・出家前の名前：高橋由美子。** 同姓同名の人気アイドル女優・歌手（1974年生）とは
  **明確に別人**——妙円さんとなった高橋由美子は、それより数十年前にすでに大学で薬学を修め、
  健康分野の著作を持つ研究者だった、まったく無関係の人物。
- **法名：妙円**——1992年10月、比叡山にて得度。
- **現在の肩書：** 薬師庵主、宗教法人自然宗佛國寺 住持職（2014年より）、「いのちの学校」校長。

## 仏教への転機となった問い

本人の語りによれば、モンブランでの怪我が回復した頃から、次のような問いを抱くようになった：

> 「人は病院で死ぬことが、自然なのだろうか？」
>
> 「生まれることも、死ぬことも、ごく自然なことで、病院で取り扱うことではないのでは？」

この問いから、長寿地域についての約5年間の研究に至る——**エクアドルのビルカバンバ**と
**山梨県の棡原村**。毛髪分析なども含め、医学系学会にも研究成果を発表した。最も重要な発見は、
聞き取り調査で出会った人々が、幸せだった瞬間として「与えられたこと」ではなく「誰かに与えた
こと」を繰り返し語ったという点——これを彼女は仏教における**「利他」**の概念と結びつけて
理解した。これが、健康分野でのキャリアから仏教へ、そしてのちの「いのちの森」（森林再生への
貢献を通じて一般の人々が利他を実践する場）へとつながる思想的な橋渡しとなった。

## 「いのちの森」と黙雷との関係

「いのちの森」を彼女が単独で創始したわけではないと見られる。系譜としては：**黙雷（開山、
宗教法人としての認証は1985年）→ 自然宗佛國寺 → 妙円（薬師庵主、2014年より住持職）→ 現在の
森林自然葬・いのちの森の運営責任者**、という流れが妥当と思われる。
[mokurai_biography_ja.md](mokurai_biography_ja.md) と
[inochi_no_mori_trademark_history.md](inochi_no_mori_trademark_history.md)（商標の経緯：1998年
出願、彼女が住持職に就く16年前）を参照——この時期の違いは、商標そのものの名付け親が彼女では
ない可能性を示唆するが、確定的ではない。一方で彼女自身の水・森への関心（1987年の阿蘇居住）は
1998年の出願よりも前にすでに存在しており、どちらの方向の影響関係もありうるため未確認。

## 未解決の論点

1. 「いのちの森」という名称・概念は、彼女自身の1992年以前の水・健康への関心にまで遡れるのか、
   それとも黙雷が先に持っていた概念を彼女が引き継いだだけなのか——時期的には後者を示唆するが
   決定的ではない。
2. 薬学における具体的な専門分野、また東京都老人総合研究所で実際にどのような研究をしていたのか
   ——「基礎生化学研究室の研究助手」以上の詳細はどこにも見当たらない。
3. 現在英語を話せるかどうか——本人からロブへの返信では「挨拶程度」とのことだったが（
   [[project_mokurai_genmyo_kagoshima_temple]] 参照）、1980年代に国内外で講演していたという
   経歴からすると、かつてはもっと話せた可能性もある。矛盾とは言い切れない——キャリア特有の
   語学力は使わなければ衰える。
4. モンブランでの事故の正確な年——「24歳の時」としか記載がなく、西暦は不明。

## 訪問における意義

彼女には、単に「黙雷のためにメールを書く人」という以上の、非常に豊かな仏門入り前のキャリア
がある——出版された健康分野の著者、テレビのコメンテーター、複数の会社の経営者。彼女自身の
経歴は黙雷のそれに劣らず興味深いと言える。良い話のきっかけとして、阿蘇での水源地暮らしと
「いのちの森」の思想には明確なつながりがあり、最初の面会で直接尋ねる価値がある。
