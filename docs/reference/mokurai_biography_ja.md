# 黙雷和尚（もくらいおしょう） — 経歴メモ

自然宗佛國寺の開山・黙雷和尚に関する調査資料。2026年10月に予定しているロブの現地訪問に向けて作成。
出典等の詳細は [[project_mokurai_genmyo_kagoshima_temple]]（アウトリーチ経緯）、
[[project_bukkokuji_visit_idea]]（訪問計画）を参照。寺院自身のサイト
（bukokuji.jimdofree.com、morino-ohaka.jimdofree.com）、Wedge Onlineの取材記事、CBC Newsの報道、
note.comのプロフィール記事から編集。いずれも二次情報・本人談を含むため、特に1991年以前の経歴は
「確定した記録」ではなく「本人の語り」として扱うこと。Claudeが直接検証したのは各ページを読んだ
範囲のみ。

## 名前について

- **本名：** 伊藤黙雷（いとう もくらい）— 寺院自身の経歴紹介より。
- **宗教者としての通称：** 黙雷、佛國寺黙雷、黙雷和尚、勧進僧黙雷。
- **「黙雷玄明」：** 御杖村に残っていた100年計画資料集の中の1997年の随筆「林野行政」に記された
  署名。「玄明」の部分は他のどの資料でも裏付けが取れておらず、未確認扱い。直接本人／妙円さんに
  確認するまでは保留とする。
- 現在85歳（2026年時点）。逆算すると生年はおおよそ1940〜41年頃。生年月日・出生地・家族構成を
  独立に裏付ける情報源は見つかっていない。

## 自己認識：勧進僧

黙雷は自らを一般的な住職ではなく「勧進僧」と位置づける。行基のように全国を歩いて仏教事業への
支援を募った歴史的僧侶の系譜に自らを置く。現代版としては「歩く→人と出会う→支援を受ける→
社会に役立つものを築く」という循環。歩行・托鉢・断食そのものを単なる資金集めではなく、宗教的
実践そのものと捉えている。

自身のあり方を象徴する歌として、次を引く：

> 人をのみ渡し渡して　おのが身は　岸に上がらぬ　渡し守かな
> （人ばかりを渡し続けて、自分自身は岸に上がることのない渡し守のようなものだ）

## 教団の理念——自然宗

- 釈尊の本来の教えへの回帰を掲げ、意図的に非宗派的な立場をとる（廻国行の中で痛感した「宗派意識」
  への批判が背景にある）。
- 信者・信徒ではなく「学徒（がくしょう）」と呼ぶ——誰もが成仏への道を歩む生涯の学び手である
  という考え方。
- 住持職・副住持職の世襲を明確に禁止——寺院は家の私有物ではなく公的な宗教施設であるべき、との
  立場。
- 文部科学省認可の宗教法人。

## いのちの森（森林自然葬事業）

- 運営は薬師庵主の釈妙円。
- モデル：自然葬の費用（永代供養料 約21万円／人）が森林の維持管理費用に充てられる循環——
  支払い→森林管理→その森が最終的な安息の地となる→森自体が存続する、という仕組み。
- 一般的な「樹木葬」とは明確に区別されている（妙円さん自身の説明より）。
- 土地面積の数値は資料によって異なる：243,000㎡（寺院自サイト）、255,000㎡（伊勢大杉谷24ha＋
  大台町茂原1.5haの合算、morino-ohaka.jimdofree.comより）、約21ha（Wedge）——未整合。直接確認
  が必要。
- 法的な位置づけは論争含み：遺骨は土をかぶせず地表に置かれており「埋葬」には当たらないとする
  立場が、黙雷自身の「法的な墓地には該当しない」との主張と表裏一体。地元からの反対もある。
  ロブ個人と寺院との関係には影響しないが、御杖村プロジェクトを寺院と公に結び付ける際の広報・
  法的リスクとして留意すべき点。
- 補助金は原則として受けない方針：自サイトのQ&Aでは「補助金は自立の精神を奪う」「国・県・
  市町村・森林組合の統制に組み込まれる」との立場を明言。ロブのプロジェクトが経産省・環境省の
  補助金に依拠している点との思想的な摩擦になり得るため、扱いには注意が必要。

## 土地について（物理的な詳細）

いずれも大台町内だが、事務所とは別の場所：

- **伊勢大杉谷：** 24ha、2007年7月5日登記。杉・檜の50〜60年生人工林12ha＋自然二次林12ha。
  極めて奥地で道路事情も悪い山間地——衛星画像だけでは地番データなしに構造物の有無を確認できず。
- **大台町茂原：** 1.5ha、2014年6月10日取得。「基本財産林」として保有。
- **寺務所（〒519-2632 大台町桧原175番地）：** あくまで事務所のみ——森林用地そのものではない。
  この住所の衛星画像に森林施設が見当たらない理由。
- **祖院（〒898-0101 鹿児島県南さつま市坊津町坊7135番地）：** 今も別途維持されており、手紙は
  三重へ転送される。「移転」というより「二つの拠点が併存している」状態に近い。

## 未解決の論点（10月の面会に向けて）

1. 1999〜2004年の「奈良県内の水源地の山村」での再生の試みは、御杖村そのものだったのか、
   それとも別の候補地だったのか。
2. 2006年の木質バイオマス発電事業（CBCのみが情報源）——具体的にどのような技術だったのか
   （ガス化／蒸気ランキン／熱利用のみ）、なぜ本人の自己記録に一切登場しないのか、なぜ中止に
   なったのか。
3. 「玄明」は実在する法諱の一部なのか、それとも誤記・混同なのか。
4. 1983年以前にどのような事業に失敗し、「裏切り」とは具体的に何だったのか。
5. 中曽根・浅沼事件との関係は、実際に裏付けられるものなのか、それとも本人の語りによる
   自己神話化なのか。
6. 大杉谷自立再生機構（2005〜2006年）で具体的に何が破綻の原因だったのか——「補助金より自立」
   という立場を御杖村プロジェクトも共有している以上、参考になる先例として詳しく聞く価値がある。
7. 土地面積の3つの異なる数値（243,000㎡／255,000㎡／約21ha）の整合性を確認する。
8. 黙雷氏・妙円さんとも英語は挨拶程度とのこと——訪問前に通訳の手配を確定する（
   [[project_bukkokuji_visit_idea]] 参照）。
