# 自らを「勧進僧」と称する

彼を理解する上で最も重要な鍵かもしれません。

**勧進僧（かんじんそう）**とは、単なる「僧侶」の別の言い方ではありません。

歴史的に勧進僧とは、仏教の建立や公共的な宗教事業への支援を募るため全国を歩いた僧侶を指します。
代表例は**行基**と東大寺建立をめぐる運動です。

黙雷は意識的に自らをこの系譜に位置づけています。

彼についての最近の記事は、勧進僧の役割を次のように組み合わせたものとして説明しています：

**全国を行脚すること＋仏教の普及＋社会事業**

——これが彼の行動の多くを説明しています。膨大な徒歩行脚、路上座禅、断食、環境活動、
山村再生、森林事業などです。

# 10. 100日間の路上座禅も、もう一つの転機だった

1991〜92年にかけて、黙雷は次を実践しました：

100日間にわたるものです。

**1991年12月8日**に始まり、**1992年3月25日**に終わりました。

直接のきっかけは**京都仏教会による寺院への出入り拒否**でしたが、黙雷はこの実践を、より
大きな問いとして位置づけました：

> **僧侶の「あるべきようは」とは何か**

つまり：

**仏教の僧侶とは本来どうあるべきか。**

彼は寺に籠るのではなく、公の場に座りました。

これが彼の後の実践を特徴づけるものとなりました。

彼はこれを：

**下座行**

と呼びます。文字通り「下から行う実践」のようなものです。

路上での座禅は、ある種の仏教の実験室となりました。

# 11. ここから「勧進僧」というアイデンティティが立ち現れる

黙雷は次第に、自らを一般的な住職としてではなく、次のように位置づけるようになります：

### 勧進僧（かんじんそう）

**歩く → 人と出会う → 支援を受ける → 社会に役立つものを築く。**

彼についての最近の独立した記事は、まさにこの側面を次のように描いています：勧進僧とは
**全国を行脚すること**、仏教の普及、そして社会貢献を組み合わせたものである、と。

そしてこれは、一見奇妙に見えることを説明する助けになります：

### 彼は托鉢や寄付を単なる「資金集め」とは捉えていませんでした。

廻国行そのものが宗教的実践となったのです。

そこから最終的に生まれた事業は、**その実践がもたらす社会的な帰結**であるはずのものでした。

# 12. そして森林へ

ここから彼の経歴は、あなたの関心と強く交わり始めます。

何十年もの歩みの末、黙雷は次第に次のことに関心を寄せるようになりました：

- 農山村の過疎化、
- 放置された森林、
- 地域コミュニティの喪失、
- 伝統的な墓制度の崩壊、
- そして政府への依存。

彼はいくつかの地域再生事業を試みました。

本人の話によれば、特に重要な事業の一つは、**2004年の大杉谷での壊滅的な台風被害**の後に
始まりました。

彼は**2005年後半**にこの地域に入り、地元の14人とともに設立したのが：

**株式会社大杉谷自立再生機構**

目的は**山村自立再生**——山村の自立的な再生でした。

彼によれば、この事業は政府補助金への依存を意図的に拒否し、次を重視しました：

**自助自立・相互扶助**

# 13. 事業は失敗した——そしてその失敗が森林を生んだ

彼の人生全体における中心的な逆説と言えるかもしれません。

山村再生事業は、外部の環境保護団体との対立の中で失敗しました。

黙雷によれば、経済的な影響は深刻なものでした。

しかしその後、予想外のことが起きました。

この対立はかえって地元支援者との関係を強め、草の根の支援者たちの協力によって、彼はおよそ：

### 243,000㎡の森林

を取得することができました。

そこから彼が展開し始めたのが：

**いのちの森——「いのちの森」。**

本人の話によれば、約**20年**にわたってこの森に取り組んできたとされ、山と森の再生モデルとして
説明されています。

独立したWedgeの取材は、現在の面積についてやや異なる数値——**約21ヘクタール**——を挙げており、
この森は彼の廻国行や寄付を通じて蓄積された資金で取得されたと説明しています。

つまり、この大枠の物語については、強い独立した裏付けがあるということです。

# 14. 「森の墓」は、実は出発点ではなかった

もう一つの、単純化されたストーリーへの重要な訂正です。

森林葬事業は、単に：

> 「僧侶が森を買い、樹木葬を始めた」

という話ではないようです。

実際の流れはこうです：

**個人的・政治的な人生**
↓
**禅の修行**
↓
**苦行**
↓
**7年半の廻国行**
↓
**日本の農村の観察**
↓
**地域再生の試み**
↓
**従来型事業の失敗**
↓
**森林の取得**
↓
**森林の再生**
↓
**財政的に自立した仕組みの必要性**
↓
**森林自然葬・いのちの森**

この最後の一歩が極めて重要です。

Wedgeの報道によれば、黙雷が森の墓を構想した背景には、同時に二つの問題を見ていたことが
あります：

1. **放置・荒廃した森林**、そして
2. 継承された墓を維持できなくなりつつある人々。

彼はこの二つを結びつけることを解決策としたのです。

# 15. 彼の発想は実は一つの経済的循環である

**人々が自然葬を求める**
↓
**長期的な寄付・支払いを行う**
↓
**その資金が森林を支える**
↓
**森林が維持される**
↓
**その森が最終的な安息の地となる**
↓
**森自体が存続する**

Wedgeは、これを森の墓に関連する収益を森林維持に充てる仕組みとして明確に説明しています。

そして黙雷自身の森林事業は、一人ひとりの「いのちの森」という小さな単位が、生き物たちが
いのちの循環に参加する、より大きな生態系としての森の一部となっていく、と説明しています。

つまりこの墓は、実際には**仏教思想に包まれた、森林保全のための資金メカニズム**なのです。

# 16. そしてこれが「自然宗」へとつながる

### 自然宗佛國寺

**釈尊の教えを師とし、仏国土建設を本願として、大慈大悲の菩薩道を実践する**

——釈尊の教えを師とし、仏国土の建設を本願として、大慈大悲の菩薩道を実践する、ということです。

教団によれば、**住持職と副住持職は世襲できない**とされています。寺院は家の私有財産ではなく、
公的な宗教施設であるべきだからです。

信徒もまた：

### 学徒——がくしょう

と呼ばれ、伝統的な**信者／信徒**ではありません。

誰もが**成仏への道を歩む学び手**であり続けるという考え方です。

## 20. そして御杖村との印象的なつながりがある

ここが、この調査が特にあなたにとって興味深くなる部分だと思います。

黙雷とあなたの**御杖村75年／25年構想**は、明らかに同じ事業ではありません。

しかし、両者は驚くほど深い構造的な発想を共有しています：

| 黙雷 | 御杖村の構想 |
|---|---|
| 損なわれた山 | 損なわれた単一樹種の森 |
| 放置された農山村コミュニティ | 衰退する農山村コミュニティ |
| 資源として扱われる森 | 遺産として扱われる森 |
| 森を使ってコミュニティを支える | バイオマスでコミュニティを支える |
| 森林再生 | 広葉樹の再植林 |
| 死は森へ還る | 古い杉はエネルギーとして還る |
| 森が経済的支援を生む | バイオマスがエネルギーを生む |
| エネルギー・経済がいのちに奉仕する | 計算資源・AIがコミュニティに奉仕する |
| 未来の世代 | 25年後の未来 |
| 精神的な責任 | 精神的な責任 |
| **いのちの森** | **光・知識へと変わる森** |

決定的な違いは、**黙雷の仕組みが「死→森」であるのに対し**、御杖村の仕組みは
**「古い森→エネルギー→知識→未来の森」**に近いという点です。

しかし両者とも、次の同じ、より深い問いに取り組もうとしています：

> **過去から受け継いだものを、未来のいのちに奉仕し続けるものへと、どう変えていけるか。**

これこそが、おそらく彼の物語が御杖村の取り組みにとって異例なほど示唆的である理由でしょう。

## まだ確立できていないこと

**まだ確定した事実とは見なせない**4つの点があります：

1. **正確な生年月日と出生地**
2. **両親・家族の背景**
3. **破綻前に携わっていた事業の具体的な内容**
4. **中曽根との関係の正確な性質、そして1960年の浅沼暗殺事件をめぐる状況**

後半の3つは非常に興味深い可能性がありますが、現時点で入手可能な情報源は、黙雷自身の回想や
二次的な報道への依存度が高すぎて、確定した事実として述べることはできません。

特に見つけたいのは、**1950〜80年代の日本の新聞アーカイブ、政治家の回顧録、臨済宗寺院の
記録**です。それらがあれば、この空白の年月をより厳密に再構成できる可能性があります。

### 次に調べるべきこと

もしご興味があれば、**現在の佛國寺についてこれ以上情報を集めること**よりも、
**黙雷の1940〜1983年の空白期間を年ごとに再構成すること**の方が価値があると考えます。特に：

**幼少期 → 政治活動 → 中曽根との関係 → 実業家としてのキャリア → 事業の失敗・裏切り →
なぜ決定的に禅へ向かったのか → 松尾太年 → 長屋真乗 → 今東光 → 1983年、すべてを手放す決断**

という流れです。

**なぜこの人物が黙雷になったのか**、その本当の物語は、この空白の中に隠されているのではないか
と考えています。
