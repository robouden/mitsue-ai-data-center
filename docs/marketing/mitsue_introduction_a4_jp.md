> 先人が植えた森が、今、村を支える力になる。

*旧菅野小学校と、その周囲の森に新たな命を吹き込む、25年間の取り組み*

## プロジェクトとは

**旧菅野小学校（御杖体験交流館）**（拠点の有力候補、最終選定は第1段階）と、その上に広がる老齢化した杉林を、農村における自給自足の生きたモデルへと変える三本柱の取り組みです。

- **森林再生** ― 杉の単一林を在来種混交林へ転換。間伐材はバイオマス燃料に。在来広葉樹はシカ・イノシシ・クマの食料源となり、農作物被害を軽減
- **バイオマスCHP** ― 杉間伐材を燃料とする熱電併給システム（電力＋熱）。太陽光・EV充電が補完し、停電時のバックアップにもなる
- **持続可能なAIデータセンター** ― 旧菅野小学校または村内空き工場を活用した小規模・高効率施設。地域エネルギーのみで稼働し、新たな雇用とインフラを生む

三つは別々のアイデアではなく、それぞれが他を可能にします。

## このプロジェクトが解決する課題

| 課題 | プロジェクトの対応 |
|---|---|
| 旧校舎・空き工場の活用先がない | データセンター兼地域拠点として再生（最終選定は第1段階） |
| 杉単一林の生態的疲弊 | 在来種混交林へ段階的転換 |
| 電力網依存・地産エネルギーなし | 杉間伐材バイオマスCHPを主力に、太陽光・EVが補完 |
| 人口減少・地域雇用の不足 | **森林組合の作業員を約2倍に増員**＋DC・エネルギー保守の新規雇用 |
| 停電・野生動物被害 | 自前のバイオマス電源で重要施設を維持／広葉樹の実がシカ等を森に留める |

## 恩恵は25年を待たずに訪れます

| 時期 | マイルストーン |
|---|---|
| 1年目 | 拠点（旧校舎／空き工場）を活用開始、国際メディアで注目 |
| 2年目 | 山林所有者が伐採収入を受け取り始める |
| 3〜4年目 | EV充電ステーション稼働 |
| 4〜5年目 | データセンター稼働・地域雇用開始 |
| 5〜10年目 | データ収益を村と森林プログラムへ再投資 |
| 25年目 | 在来混交林が完成、モデルを世界へ公開 |

**現時点で確保済みの資金はまだありません。** まず必要なのはフェーズ0・1（フィージビリティ調査・法人設立・初期アウトリーチ）を動かす**シードマネー（種銭）**です。これが整い次第、林野庁補助金・経産省/NEDO補助金・村の再エネ推進交付金（2/3〜3/4補助）・FIT/FIP・J-クレジット・データセンター収益・インパクト投資など、複数の財源を積み重ねて自立運営を目指します。
