このアプリについて / About this app

御杖村の母樹(たねを採る木)を記録するための調査アプリです。
A field survey app for recording mother trees (seed-source trees) around Mitsue Village.

使い方 / How to use

  1. 「新規登録」からアカウントを作成し、確認メールのリンクを開いてください。
    Create an account via "Sign up", then open the link in the confirmation email.
  2. ログイン後、「記録」画面で木の場所（GPS）・樹種・状態を入力して送信します。
    After signing in, use "Record" to log the tree's location (GPS), species, and condition, then submit.
  3. 「図鑑」で樹種の写真を確認できます。
    Use "Guide" to browse reference photos by species.
  4. 「一覧」で自分がこれまで記録した木を確認できます。
    Use "List" to review the trees you've recorded so far.

ご不明な点があれば村の担当者にご連絡ください。
If you have questions, please contact the village project team.
