## 2. Kagoshima land-registry (登記) lookup on the old address

The essay's colophon gives an old-style address, **鹿児島県坊津町坊七一三五** ("7135, Bō, Bōnotsu-chō"), written without hyphens in the original — most likely a **地番 (chiban)**, the land-registry lot number, not a post-reorganization residential address (住居表示). Bōnotsu-chō merged into Minamisatsuma City in 2005, but chiban numbers typically survive municipal mergers unchanged, so the modern registry search would likely be under **鹿児島県南さつま市坊津町坊 字（unknown）7135番**.

This mirrors the method already used successfully for the Mitsue land-ownership question — see [[reference_touki_registry_lookup]] (¥331 per registry PDF via touki.or.jp, which covers all of Japan, not just Nara).

**Steps for Rob to run (requires the touki.or.jp paid service, not accessible via this session's tools):**
1. Go to https://www1.touki.or.jp (登記情報提供サービス) and log in / register if not already set up.
2. Search 土地 (land) registry for: 鹿児島県南さつま市坊津町坊, 地番 7135 (try nearby numbers too, e.g. 7135番地の1/2, if an exact match isn't found — chiban can be subdivided over time).
3. Pull the 登記事項要約書 or 全部事項証明書 (¥331 tier is usually enough, same as the Mitsue case).
4. What to look for: current registered owner name (could reveal whether it's still held by a religious corporation, a private individual/heir, or the municipality); any change-of-ownership history, which could show when/if the temple was formally dissolved or the land sold.

**Caveat:** if the address in the essay is actually a post-reorganization jūsho (residential display address) rather than a chiban, this search may return nothing — in that case, the 8/9 above should be tried first, since local staff can usually translate an old-style address into the correct current chiban on request.
