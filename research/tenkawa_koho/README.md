# Tenkawa Village (天川村) Council Research — from 広報てんかわ

**Read this first: this is NOT a minutes archive.** Tenkawa Village does not publish full council meeting minutes (議事録) online — no kaigiroku.net-style system, no minutes PDFs. The only digitized public archive of council activity is **広報てんかわ**, the monthly public-relations bulletin, which includes a "**議会だより**" (council news) section each issue that *summarizes* that month's/quarter's council session — agenda items, budget votes, ordinance changes, appointment consents. Every finding in this folder traces back to that summary, written by village staff, not to a verbatim transcript. This mirrors `research/council_minutes/` (the Mitsue full-minutes archive) in structure and CSV schema, but the underlying source material is fundamentally thinner — treat the two archives' findings as not directly comparable in depth.

Source index: https://www.vill.tenkawa.nara.jp/office/publicrelations (23 pages, paginated `/page/2` .. `/page/23`)
Coverage achieved: issue #320 (2003-09-01) through #593 (2026-07-07) — **274 of 274 issues in the confirmed range, 100% enumerated and downloaded**, monthly cadence, no gaps in issue-number sequence.

## Pipeline
1. **Enumerate**: fetched all 23 index pages (`curl`, 0.3s delay), parsed each issue's number/date/PDF URL from the `archivebox` blocks. All 274 issues resolved with zero gaps in sequence. Saved as `pdf_links.csv`.
2. **Download**: all 274 PDFs pulled via `curl`, 0.3s delay. **All 274 succeeded** (verified >2KB); zero download failures.
3. **Extract text**: `pdftotext -layout` on all 274. **273 of 274 had a real embedded text layer** (including the earliest, #320 from 2003 — the 2016 re-hosting of pre-2016 issues preserved real text, it did not re-scan them as flat images, contrary to what the original task brief assumed). Only **one issue (#473, 2016-07-01) was a genuinely flat scanned/image PDF** with no text layer; it was OCR'd via `pdftoppm -r 300` + `tesseract -l jpn` (the `jpn` language pack is not installed system-wide on this machine — it was downloaded manually to a scratch `TESSDATA_PREFIX` for this run) — OCR succeeded and yielded ~14,000 CJK characters of readable (not hand-verified line-by-line) text.
4. **Locate council section**: regex-matched a (whitespace-tolerant) "議会だより" heading, then took a bounded window of text following it. **124 of 274 issues (45%) had an identifiable council-news section**; the other 150 did not (see Limitations — this is expected, not a failure).
5. **Structured outputs** (below).

## Files in this folder
- `pdf_links.csv` (274 rows) — issue_number, date, source PDF URL, file extension, source index page.
- `raw/` — all 274 downloaded PDFs, named `{issue_number}.pdf`.
- `text/` — all 274 extracted text files, named `{issue_number}.txt` (273 via `pdftotext -layout`, 1 via OCR — #473).
- `council_summary.csv` (124 rows) — one row per issue with a located council section: issue_number, date, agenda_items (◇/▽ bullet lines pulled from the section), yen_amounts (all 千円/万円/円 figures found in the section), contractors (company names with 株式会社/有限会社/合同会社 suffix found in the section), notable_topics (契約/入札/指名/落札 keyword flags), source_file.
- `contractors.csv` (7 rows) — every company-suffix name found anywhere in a contract/bid-adjacent context across the **full** corpus (not just the windowed council section), each individually classified as a real council contract award vs. a false positive (product recall, outsourcing notice, unrelated business story, etc.) — see Limitations for why this file is short.
- `no_council_section.csv` (150 rows) — every issue where no 議会だより heading was found, logged rather than silently skipped.
- `download_failures.csv` (0 rows) — kept for pipeline-completeness/audit even though empty.
- `extract_failures.csv` (1 row, resolved) — logs #473's initial pdftotext failure; superseded once OCR succeeded (see `text/473.txt`).
- `timeline.md` — chronological narrative of notable findings, evidence-first with direct quotes and source citations, mirroring `research/council_minutes/timeline.md`'s style.

## Top-line findings
1. **村本建設株式会社 (Muramoto Construction) — one confirmed contract, 2007.** Issue #370 (2007-11-30) reports that on 2007-11-12 the village ran a 指名競争入札 (designated/invited bid, not open bid) for the Central-district simple water-supply construction, split into 3 zones — **and Muramoto Construction (Nara Main Branch) won all three zones.** This is the only mention of this company anywhere in the 274-issue, 2003-2026 corpus (confirmed by full-text grep, not just the council-section window). Full quote and context in `timeline.md`.
2. **The 2009 bribery case itself is never mentioned.** A targeted keyword search (贈収賄/収賄/起訴/判決/地裁/有罪) across all 2006-2010 issues found zero genuine hits (one false-positive hit in #356 about an unrelated general-legal-awareness article on prosecution review boards). This absence is expected — village PR bulletins do not typically report on their own contractor's criminal prosecution — but it is worth recording explicitly as a checked, not assumed, absence.
3. **Bid-method language appears in 20 issues, but almost all are generic recurring bidder-registration notices** (指名競争入札参加資格審査 — a standing call for firms to register as pre-qualified bidders), not individual contract-award reports. **Issue #370 (the Muramoto case) is the only one of these 20 issues reporting an actual awarded contract with a named winner.** This is a structural property of the bulletin — it is why `contractors.csv` has only 7 rows total, most of which are false positives on closer reading.
4. **No Mitsue-style recurring-contractor or official-surname-overlap pattern could be established** — the sample of confirmed contract-award mentions in this archive is n=1 (Muramoto, 2007). That's too small a sample to claim any pattern; it should be read as "the bulletin format doesn't surface this kind of detail," not as "Tenkawa has fewer such patterns than Mitsue."

## Limitations / honesty notes
- **This is a summary, not verbatim minutes** — repeated for emphasis. Council sessions in this dataset are represented by a few paragraphs of staff-written summary each, not a speaker-by-speaker transcript. There is no equivalent of Mitsue's `nakashima_log.csv` (tracking one official's speaking turns) possible from this source material — individual councilor names and direct quotes essentially never appear in 広報てんかわ's council section; the Mitsue archive's per-speaker granularity is a feature of full minutes that this bulletin format does not have.
- **150 of 274 issues (55%) have no identifiable council section.** This includes genuine no-session months (council meets ~4x/year for regular sessions, more with extraordinary sessions, but the monthly bulletin publishes every month) and cases where the section may exist in the source PDF under different phrasing or was folded into another page without a standalone heading. `no_council_section.csv` lists all 150 rather than silently dropping them; spot-checking a handful before relying on the "no section" claim for any specific issue is advisable if it matters.
- **6-thousand-character window per issue**: council sections were captured as a bounded text window following the heading, cut off at a heuristic stop marker (chart/decimal-summary headings that reliably follow the text portion). For an unusually long 議会だより section this could in principle truncate late content; spot-checks on several sampled issues (#500, #370) did not show truncation problems, but this was not exhaustively verified for all 124.
- **`pdftotext -layout` scrambles Tenkawa's 2-column magazine layout** in places, and headings in large decorative fonts sometimes extract with inserted spaces (e.g. "議 会 だ よ り" instead of "議会だより") — the heading regex and money/keyword regexes were made whitespace-tolerant to compensate, but this is a real source-format quirk worth knowing if searching `text/*.txt` manually.
- **Only 1 of 274 issues (#473, 2016-07-01) required OCR.** The `jpn` Tesseract language pack is not installed system-wide on this machine; it was downloaded to a scratch directory for this task. If re-running this pipeline elsewhere, confirm `tesseract --list-langs` includes `jpn` first.
- **Contractor/money extraction is comprehensiveness-limited, not accuracy-limited.** Unlike Mitsue's full minutes (which name contract sums, bid counts, and estimate ratios routinely), Tenkawa's bulletin rarely states exact contract yen amounts or bidder counts for construction awards — `council_summary.csv`'s yen_amounts column mostly captures budget totals and settlement figures (決算/予算), not individual contract sums, because that is what the source text actually contains.
- **Money-amount and company-name regex extraction can still mis-capture** in dense paragraphs (same caveat as the Mitsue archive) — verify any specific figure or name against the cited `source_file` before using it externally.
- **2003-2016 vs. post-2016 hosting**: pre-2016 issues (#320-roughly #440s) were re-uploaded to `/wp-content/uploads/2016/03/` in 2016 (visible in `pdf_links.csv`'s URL paths), evidently as part of a 2016 website migration — but this re-hosting preserved the original text layer rather than flattening to scanned images, which is why OCR was needed for only 1 issue rather than the whole pre-2016 range the original task brief anticipated.
